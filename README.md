# Calculadora de IMC con validacion

# Descripcion 

En este proyecto se implemento el uso de herramientas practicas como la calculadora,agrgando datos del alumno, todo esto desarrollado por primera vez en python, esperando que hya sido buena y genrando un aprendizaje favorable.
Todo fue diseñado para la comodidad del cliente con resulatdos seguros y precisos.
En esta se agregaron datos y comandos didacticos en bucle,numeracion y texto,mencionando uno es esepcial qu evita dejar espacios en vacio como lo es "try-except" muy valiso.

# Funcion principal 

Entrada segura : verifica y valida que ninguna entrada que en vacio o solo con espacios
Control de excepciones : Reconoce entraradas no numericas(como lo son textos o simbolos), esto para evitar fallos en la ejecusion final.
Validacion de rango : Determina que los valores agregados como la edad,el peso y la estaura sean legibles y mayores a determinado numero como 0.
Calculo matematico : Obtenie los datos agragados por el usuario y calcula el IMC dado el resultado el decimal(float)
